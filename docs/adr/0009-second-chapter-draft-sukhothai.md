# ADR-0009: บทที่สอง (ร่าง) — สุโขทัย–อยุธยาตอนต้น + เลือกบทได้

**Status:** Accepted (เนื้อหาเป็น **ร่าง** — ยังไม่ผ่านที่ปรึกษาประวัติศาสตร์)
**Date:** 2026-09-23

## Context

ROADMAP.md กำหนดให้เนื้อหาอีก 5 บทรอที่ปรึกษาประวัติศาสตร์ และ ADR-0007 Addendum 5/6 เลื่อนการออกแบบ "แผนที่
ต่อบท" กับ "โครงเหตุการณ์ประจำฤดู" ไว้จนกว่าจะมีเนื้อหาบทจริงอีกอย่างน้อยหนึ่งบท — ลีมอบให้ Claude ตัดสินใจแทน
และเลือก "บทที่ 2 แบบร่าง" (23 ก.ย. 2026) เพื่อพิสูจน์ว่าระบบหลายบททำงานได้จริงตั้งแต่ต้นจนจบ

## Decision

**1. บทที่เลือก: บทที่ 3 ของ 6 "สุโขทัย–อยุธยาตอนต้น"** (`content/chapters/sukhothai-ayutthaya.ts`,
พุทธศตวรรษที่ 18–20) — ต่อจากบทต้นรัตนโกสินทร์ (บทที่ 4) ในลำดับเวลาพอดี และมีโครงที่เข้ากับกลไก "ไผ่ลู่ลม"
เดิมอย่างเป็นธรรมชาติ: บ้านเมืองที่เพิ่งตั้งตัวระหว่างสองอำนาจภายนอก — **จักรวรรดิเขมร** ที่อำนาจกำลังเสื่อม
กับ **ราชสำนักจีน** ที่รับคณะทูตบรรณาการจากทั่วภูมิภาค — พึ่งฝ่ายใดมากเกินไปก็กลายเป็น "เมืองประเทศราช"

**2. กลไกเหมือนเดิมทุกประการ ต่างแค่ชื่อ/ข้อความ** (ตามที่ลีตัดสินใจใน ADR-0007 Addendum 4) — ค่าใช้จ่าย กฎ ผล
ของอาคาร/วิทยาการ ตัวเลขในเงื่อนไขตอนจบ ที่นั่ง ใช้ค่าจากบทเดิมทั้งหมด (ไฟล์บทใหม่ spread จากบทเดิมแล้ว
เปลี่ยนเฉพาะชื่อ) — **มีเทสต์บังคับ**: ตัดฟิลด์ที่เป็นหน้าตาทิ้งแล้วเทียบ ต้องเท่ากันทุกไบต์ ใครแก้ตัวเลขในบทใหม่
โดยไม่ตั้งใจเทสต์จะล้ม ตัวอย่างชื่อที่ใช้ (ควรให้ที่ปรึกษาตรวจ): ทำนบพระร่วง (ชลประทาน), กองช้างศึก (แทน
"ดินปืน" ที่ผิดยุค), ลายสือไทย (แทน "การพิมพ์"), กำแพงตรีบูร, ตลาดปสาน, หอไตร, ท่าสำเภา, ตอนจบ "ในน้ำมีปลา
ในนามีข้าว" / "ธรรมราชา" / "เมืองประเทศราช", แคว้นล้านนา/ละโว้/นครศรีธรรมราช

**3. ใช้แผนที่เดิม** — สมมติฐานใน ADR-0007 Addendum 6 ว่า "บทอื่นอาจใช้ภูมิศาสตร์ลุ่มน้ำเดียวกันต่างยุค" —
ทดสอบแล้วใช้ได้จริง ไม่ต้องแก้ `hex.ts`

**4. ข้อความเฉพาะยุคย้ายเข้าเนื้อหาบท** — เจอข้อความที่ผูกกับยุคต้นรัตนโกสินทร์ฝังอยู่ในโค้ด (คำขาด "เรือปืนปิด
ปากแม่น้ำ" ใน `powers.ts`/`views.ts`/`BambooTab`, "กรุงนที" ใน `GoalsTab`/`Modals`, ข้อความแนะนำเกม, ชื่ออาณาจักร
ของผู้เล่น `MY_NAME` ใน `store.ts`) — เพิ่ม `ChapterDefinition.flavor` (`ultimatum`, `intro` พร้อม placeholder
`{P}`/`{capital}`/`{years}`) ย้ายข้อความเดิมของบทต้นรัตนโกสินทร์ไปไว้ตรงนั้นแบบไม่เปลี่ยนคำ ชื่อเมืองหลวง/
อาณาจักรอ่านจากเกมและที่นั่งของบทแทน

**5. `ChapterManifest.historianReviewed: boolean`** — ทั้งสองบทตอนนี้เป็น `false` UI แสดงป้าย "ร่าง" ในหน้าเลือก
บท/ห้องรอ/HUD เพื่อไม่ให้ใครเข้าใจว่าเนื้อหาผ่านการตรวจแล้ว

**6. เลือกบทได้ทุกทาง** — engine: `CHAPTER_LIST` (เรียงตาม `manifest.order`), `DEFAULT_CHAPTER_ID` —
server: `chapterId` (ไม่บังคับ) ใน `POST /games` และ `POST /lobbies` ตรวจกับ registry (ไม่รู้จัก → 400) ห้องรอเก็บไว้
แล้วส่งต่อให้เกมตอนเริ่ม — web: ปุ่ม "เริ่มใหม่" เปิดหน้าเลือกบท, ห้องรอมีตัวเลือกบท, "เล่นอีกครั้ง" ใช้บทเดิม

## ผลต่อสิ่งที่เคยเลื่อนไว้ (ADR-0007 Addendum 5/6/7)

เงื่อนไข "รอเนื้อหาบทจริงอีกหนึ่งบท" ครบแล้ว และคำตอบคือ **ยังไม่ต้องทำ**: บทที่สองใช้แผนที่เดิม ฤดูเดิม (ฝน/หนาว/
ร้อน ของภูมิอากาศเดียวกัน) และเหตุการณ์ประจำฤดูเดิม (น้ำท่วมที่ราบลุ่ม ฯลฯ) ได้อย่างสมเหตุสมผลโดยไม่ต้องแก้ —
จึงไม่ออกแบบ "แผนที่ต่อบท"/`SeasonalEventDef` ตอนนี้ (ถ้าออกแบบตอนนี้ก็ยังเดาอยู่ดีว่าบทไหนต้องการอะไร)
ทำเมื่อมีบทที่**ต้องการ**แผนที่หรือฤดูต่างออกไปจริง (เช่นบทก่อนประวัติศาสตร์หรือบทสมัยใหม่)

## Consequences

- มี 2 บทในระบบ — ข้อจำกัด "registry ไม่ใช่ object ที่ส่งเข้า `createGame`" (ADR-0007) เริ่มมีผลจริงแล้ว แต่ทุกเส้นทาง
  สร้างเกม (local, `POST /games`, ห้องรอ, replay) ใช้บทที่ลงทะเบียนเสมอ จึงไม่มีปัญหาในทางปฏิบัติ
- Legacy ข้ามบทใช้ได้ทันที: จบบทหนึ่งแล้วเริ่มอีกบท ได้โบนัสจากบทล่าสุด (ADR-0007 Addendum 9)
- เนื้อหาบทใหม่ทั้งหมดเป็นร่างของ Claude — **ต้องให้ที่ปรึกษาประวัติศาสตร์ตรวจ** ก่อนเปลี่ยน `historianReviewed`
- เทสต์: engine 5 เคส (`chapter-sukhothai.test.ts`: validate/ลงทะเบียน/ป้ายร่าง, กลไกเท่ากันทุกไบต์, createGame +
  คำขาดไม่ใช่เรือปืน, บอทเล่นจบทั้งเดี่ยว 20 เกมและหลายคน 5 เกมโดยไม่ละเมิด invariant, chronicle ใช้ชื่อตอนจบของบท),
  server 3 เคส (`chapters.test.ts`), web 1 เคส (หน้าเลือกบท → เกม/intro/HUD ใช้บทที่เลือก)
