# ADR-0008: บรรณาการ / งานบุญ / รวมแผ่นดิน ระหว่างผู้เล่นมนุษย์

**Status:** Accepted
**Date:** 2026-09-23

## Context

ADR-0006 ข้อ 4 จงใจให้ `tribute`/`festival`/`annex` ใช้ได้แค่กับ AI เพราะ "การผนวกมนุษย์อีกคนต้องมี flow
ยอมแพ้/พ่ายที่ชัดเจน ไม่ใช่แค่จ่ายเงินซื้อ" และถือเป็นการตัดสินใจเชิงออกแบบของลี — ลีมอบให้ Claude ตัดสินใจแทน
(23 ก.ย. 2026) ADR นี้บันทึกสิ่งที่ตัดสินใจและเหตุผล เพื่อให้ลีกลับมาแก้ได้ง่ายถ้าไม่ตรงใจ

## Decision

**1. บรรณาการให้มนุษย์ = ของขวัญจริง** — ผู้ส่งจ่ายค่าบรรณาการตามฤดู (`costs.tribute` × ตัวคูณการทูต) และ
**ผู้รับได้รับทรัพย์เท่าที่จ่ายจริง** (กับ AI ทรัพย์หายไปเฉย ๆ เพราะ AI ไม่มีคลังให้ใช้) ความสัมพันธ์ +`tributeGain`
เหมือน AI — เหตุผล: ระหว่างผู้เล่นด้วยกัน การจ่ายแล้วของหายไปเฉย ๆ ไม่มีความหมายเชิงเกม แต่การส่งทรัพย์ให้กันจริง
เปิดทางให้ช่วยเหลือพันธมิตร/ซื้อใจเพื่อนบ้านได้

**2. งานบุญร่วมกับมนุษย์ = เหมือน AI** — จ่ายศรัทธา ความสัมพันธ์ +`festivalGain` ไม่มีของขวัญ (งานบุญคือการ
ใช้ศรัทธาไปกับพิธี ไม่ใช่โอนทรัพย์)

**3. "ผนวก" มนุษย์ = ข้อเสนอรวมแผ่นดิน ที่อีกฝ่ายต้องยอมรับเอง** — ใช้คำสั่ง `annex` เดิม แต่ถ้าเป้าหมายเป็น
มนุษย์จะกลายเป็น `DiplomaticProposal` ชนิดใหม่ `kind: 'union'` (โครงเดียวกับข้อเสนอสงบศึกใน ADR-0006) —
ไม่มีใครถูกผนวกโดยไม่ยินยอม ส่วนการยึดด้วยกำลังยังเป็นทางเดิม (ยึดเมืองหลวง → ล่มสลาย)

- เงื่อนไขตอนเสนอเหมือนผนวก AI: ไม่อยู่ในสงคราม, ความสัมพันธ์ ≥ `annexThreshold`, จ่ายไหว — แต่**ยังไม่จ่าย**
  (จ่ายตอนอีกฝ่ายยอมรับ ไม่ต้องคืนเงินถ้าถูกปฏิเสธ)
- ยอมรับ: ผู้เสนอจ่ายค่าผนวกตามฤดูปัจจุบัน ได้เมืองและทัพทั้งหมดของผู้ยอมรับ (โค้ดร่วมกับการผนวก AI ใน
  `absorbFaction`) ผู้ยอมรับออกจากเกมด้วย**ตอนจบใหม่ "รวมแผ่นดิน"** (`EndingId` `'union'`) — ไม่ใช่ "เถ้าถ่าน"
  เพราะการยอมถอยโดยสันติไม่ควรถูกนับเหมือนแพ้สงคราม (ตอนจบนี้ไม่ได้ประเมินตอนท้ายเกม จึงไม่อยู่ใน
  `ENDING_ORDER` — ตั้งตรง ๆ ตอนยอมรับ และ `finishGame` คงไว้)
- ถ้าเงื่อนไขเปลี่ยนก่อนตอบ (เกิดสงคราม หรือผู้เสนอทรัพย์ไม่พอแล้ว) ข้อเสนอเป็น**โมฆะ** ไม่ทำครึ่ง ๆ — และ
  ประกาศสงครามจะลบข้อเสนอรวมแผ่นดินที่ค้างระหว่างสองฝ่ายทันที
- UI ถามยืนยันก่อนยอมรับ เพราะย้อนกลับไม่ได้

**4. กันเกมค้าง** — ผู้ยอมรับเป็นคนสั่ง (ไม่ใช่ผู้เสนอ) ถ้าผู้เสนอกดจบฤดูไปแล้ว พอผู้ยอมรับออกจากเกม จะไม่มีมนุษย์
ที่ยังไม่จบฤดูเหลือให้กดอีก ฤดูจะค้างตลอดไป — การยอมรับจึงจบฤดูให้เองในกรณีนั้น (มีเทสต์ยืนยัน)

## Options Considered

| ทางเลือก                                              | ข้อดี                          | ข้อเสีย                                                                                          |
| ----------------------------------------------------- | ------------------------------ | ------------------------------------------------------------------------------------------------ |
| บรรณาการให้มนุษย์แล้วทรัพย์หายไปเหมือน AI             | โค้ดเหมือนเดิมทุกอย่าง         | ไม่มีเหตุผลในเกมที่ผู้เล่นจะทำ                                                                   |
| **บรรณาการ = ของขวัญจริง (เลือก)**                    | ช่วยพันธมิตร/ซื้อใจได้จริง     | เปิดทาง "ป้อนทรัพย์" ให้เพื่อนในทีม — ยอมรับได้ เพราะผู้ส่งเสียทรัพย์เท่ากันและเกมไม่มีทีมตายตัว |
| ผนวกมนุษย์ด้วยเงินเหมือน AI                           | ง่าย                           | บังคับผู้เล่นอื่นออกจากเกมโดยไม่ยินยอม                                                           |
| **ข้อเสนอรวมแผ่นดินที่ต้องยอมรับ (เลือก)**            | ยินยอมเสมอ, ใช้โครงข้อเสนอเดิม | ต้องเพิ่ม `ProposalKind`/`EndingId` ใหม่                                                         |
| flow ยอมแพ้ระหว่างสงคราม (เงื่อนไขสงบศึกแบบเสียเมือง) | สมจริงกว่า                     | ใหญ่กว่ามาก ต้องออกแบบการต่อรองเงื่อนไข — เก็บไว้ถ้าลีอยากได้                                    |

## Consequences

- `ProposalKind` = `'peace' | 'union'`, `EndingId` เพิ่ม `'union'`, `data.ts` `ENDINGS.union` — ทุกบทต้องมี
  ตอนจบ `union` ในเนื้อหาของตัวเอง (`ENDINGS` เป็น `Record<EndingId, …>` ครบทุกค่า)
- `tribute`/`festival`/`annex` ใช้กับมนุษย์ได้แล้ว — ปิดข้อ 4 ของ ADR-0006
- ผู้ที่ยอมรับรวมแผ่นดินยังได้ Legacy ตอนจบเกมตามปกติ (ADR-0007 Addendum 9) — คำนวณจาก state ตอนจบ ซึ่ง
  ไม่มีเมืองเหลือแล้ว โบนัสจึงต่ำ
- เทสต์: engine 10 เคสใน `packages/engine/test/human-diplomacy.test.ts` (ของขวัญจริง, งานบุญไม่มีของขวัญ,
  สงคราม/ตัวเอง, เสนอไม่จ่าย+เกณฑ์ความสัมพันธ์, ยอมรับ → ย้ายทุกอย่าง+ตอนจบ union, ตอนจบคงอยู่หลัง
  `finishGame`, โมฆะเมื่อทรัพย์ไม่พอ, ไม่ค้างฤดู, ปฏิเสธ, สงครามลบข้อเสนอ) + web 1 เคส (ปุ่ม/ข้อเสนอขาเข้า)
